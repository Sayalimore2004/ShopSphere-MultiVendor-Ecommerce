# ShopSphere - Multi-Vendor E-Commerce Website

ShopSphere is a responsive multi-vendor e-commerce website developed using HTML, CSS, and JavaScript. The project provides a complete frontend shopping experience with product browsing, search, filtering, seller stores, cart management, checkout, user authentication pages, and order management.

## 🚀 Features

- Responsive e-commerce interface
- Product browsing and product details
- Product search functionality
- Category-based product filtering
- Price-based filtering
- Seller/vendor stores
- Seller information and store pages
- User registration and login
- User profile
- Shopping cart
- Quantity management in cart
- Checkout page
- Order confirmation
- Order history
- Payment option interface
- Responsive design for desktop, tablet, and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design
